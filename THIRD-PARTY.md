# Composants tiers embarqués

Ce projet embarque des assets tiers dans `assets/`. Chaque asset est
distribué sous sa propre licence ; le code source de ce projet reste sous MIT.

| Asset | Source | Licence |
|---|---|---|
| `assets/fonts/Inter-Regular.ttf` | Inter v4.1 (rsms) | SIL Open Font License 1.1 (voir `assets/fonts/OFL.txt`) |
| `assets/icons/*.svg` | Lucide (lucide.dev) v1.61.0 | ISC |

Le texte complet de la SIL OFL 1.1 est fourni dans `assets/fonts/OFL.txt`
(copie de la licence officielle du projet Inter) — requis par l'OFL lors de
la distribution de la police. Les icônes Lucide sont sous licence ISC
(permissive, équivalente MIT).
